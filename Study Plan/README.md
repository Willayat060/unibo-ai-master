## 4. Weekly Time Allocation Budget (Target: 28–32 Hours / Week)

Assuming lectures occupy daytime slots, structure independent self-study across the week:

- **FAIKR (30% ~ 9 hrs/wk)**: High volume of theoretical algorithms (Search, Planning, Games, Logic, Bayes Nets) + optional challenge implementation.
- **MLDM (25% ~ 8 hrs/wk)**: Balance between Data Warehouse theory (DFM, Data Lake) and hands-on ML implementation in scikit-learn.
- **StatMathAI (25% ~ 8 hrs/wk)**: Problem sets, matrix algebra derivations, PCA exercises, past exam questions.
- **ILAI (20% ~ 6 hrs/wk)**: Python memory model & NumPy vectorization, followed by Prolog recursion and MiniZinc modeling.
